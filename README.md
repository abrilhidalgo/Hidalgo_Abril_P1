# Sistema de Control de Inventario

**TPI Programación 1** · Tecnicatura Universitaria en Programación a Distancia · UTN
**Alumna:** Hidalgo Abril Antonella

Programa en Python con menú para controlar el stock de una ferretería: carga de herramientas, consulta de stock, reporte de agotados, alta de productos y registro de ventas e ingresos, con validación de todos los datos que ingresa el usuario.

## ▶️ Cómo ejecutarlo

Requiere Python 3. Desde una terminal, en la carpeta del proyecto:

```
python inventario.py
```
